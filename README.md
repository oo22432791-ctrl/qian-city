## 在这座城市生活

每个生活日都需要安排体力、健康、心情与现金：今天做多少工作，是否先吃顿饭，要不要去见一个人，什么时候回家休息。回到出租屋，可以使用厨房、整理住处、安排睡前活动，再通过睡眠推进下一生活日。

城市里有广场、河岸、市场、图书馆、艺术街区、山坡和不同的职业场所。地图上的设施对应具体行动；不同地点也会遇到人物、生活插曲与可继续回访的内容。手机集中提供生活、人物、职业和小游戏入口，方便查看下一步方向。

城市探索从寻找一个具体目的地开始。想补充状态时去市场或诊所，想积累职业能力时去图书馆与工作场所，想换换心情时去广场、河岸或山坡。熟悉地图后，也可以把几件事情安排在同一次出行里。

## 把住处慢慢变成自己的家

回家以后，厨房、冰箱、工作桌、床铺和卫浴都有各自的用途。你可以采购食材，按食谱做饭，查看库存，再决定今天把多少资金留给生活补给。厨房储备跟随对应住所保存，换一个住处也需要重新考虑自己的生活安排。

家具提供了持续经营的目标。挑选并布置家具，会改变住所里的可用设施和休息收益；不同家具的用途、价格与效果可以在购买时查看。出租屋、晴川公寓、花庭公馆与澄曜复式，也有不同的空间布局与居家行动。

当资金与条件允许时，可以考虑购置住宅、改善居住条件。也可以继续住在熟悉的出租屋，把收入优先用于职业设备、田地或其他成长方向。决定下一笔钱花在哪里，是生活经营的一部分。

## 今天的天气，也是今天的计划

城市会随生活日呈现季节与天气变化。出门前看看预报，可以帮助你决定先去室内学习，还是把户外活动留到更合适的时候。天气会进入出行、部分活动与农场照料的安排，准备雨具和设备也有实际用途。

白天把事情安排好，晚上再通过睡前活动与睡眠收尾。睡眠推进生活日，并连接恢复状态、作物成长和次日安排；正在经营田地时，记得留意成熟时间，再回到农场完成收获与出售。

各职业拥有独立等级与经验。选定一个方向后，通过它对应的行动、订单或经营逐步成长；切换路线时，各自的进度保留。

| 职业 | 从哪里开始 | 可以逐步体验的内容 |
| --- | --- | --- |
| 务农 | 职业农场的第一块田地 | 播种、照料、收获与出售，积累资金后扩展经营 |

## 从一块田地开始经营

职业农场初始开放一块地，其余两块需要花钱解锁。到对应田地播种、浇水或施肥，等待作物成熟，收获后出售；作物、天气与资金安排共同构成经营节奏。

农场不是一个点击就领工资的入口。投入种子、照料作物、推进生活日，再把收成卖出去，才完成一轮经营。截图展示了播种、浇水后的田地和仍未解锁的地块。

## 在雾河岸慢下来

河岸可以探索、遇见人物，也有独立的钓鱼玩法。准备阶段选择已开放的水域、鱼饵和落点；抛竿需要掌握力度，咬钩时及时扬竿，挂鱼后再通过收线与放线控制张力。

鱼会挣扎，拉得太紧可能断线，放得太松可能脱钩。一行最多三竿，鱼获会记录种类与最大重量，并参与城市收益结算。鱼类图鉴、水域解锁和钓具让钓鱼有可以继续追求的目标。

## 原潮荣耀：可以长期投入的游戏内游戏

## 不赶进度时，还能玩些什么

钓鱼与原潮荣耀之外，城市还有适合短暂休息的独立小游戏。可以选择自己喜欢的一项重复体验，逐步熟悉规则、积累记录，再回来处理当天的其他事情。

| 玩法 | 一局里需要做的选择 |
| --- | --- |
| 城市骑行 | 选择路线，观察四段路况，在不同骑行节奏间切换，争取连击与更好成绩 |
| 城市夜跑 | 根据街道路况选择稳步、绕开或冲刺，在分数与体力消耗之间取舍 |
| 放风筝 | 看当前风向选择控风动作，完成四回合，收集城市风筝卡 |
| 空场投篮 | 根据篮筐距离选择投篮动作，完成四回合，积累球场票根 |
| 园艺 | 体验种植与照料，把收获放进日常成长安排 |

这些玩法会留下成绩、收藏或进度，也会与城市的状态和结算相连。部分玩法按生活日限制次数，结束后可以查看结果，再决定继续探索还是回家休息。

## 给猫咪留一个回家的位置

城市里的流浪猫阿喵也有自己的陪伴过程。先通过回访与互动积累熟悉度，再为家里准备猫爬架；满足条件后，可以正式把它带回家。

收养后，住所会出现猫咪陪伴入口。每天回家照料它，或在家里睡觉，都能获得相应的生活恢复。随着陪伴进度增加，街角的一次相遇会成为住处里持续存在的日常。

## 人与生活会留下记录

与邻居交流、赠送礼物、参与人物故事和约会，关系会逐步发生变化。生活插曲中的选择、职业经历与一些城市回访会留下记录，可以通过手机回看。

这份作品希望让经营与成长有日常生活的落点：记得自己住在哪里，熟悉某条街，知道下次想见谁，也能决定把钱与精力花在哪件事上。

人物交流也有可以继续跟进的事项。手机联系人里能查看相处进展、尚未完成的约定，以及下一次见面方向。人物故事中的选择会留下不同回应，一些完成后的影响还会进入经营、生活或后续回访。

例如，带回家的旧台灯、一次电台来电、市场里的一次采购，都会让普通的出行多一段记忆。有的选择可以立即看到结果，有的会在之后的生活日留下新的行动入口，值得再去原来的地方看看。

## 给自己定一个阶段目标

试玩时可以先选一个容易观察进展的目标，再逐步拉长自己的计划：

- **安顿下来**：熟悉补给、厨房、床铺与手机，完成一个能顺利收尾的生活日。
- **赚到一笔自己的钱**：完成职业行动或短委托，务农则体验一次播种到出售的完整周期。
- **做一次有用的投入**：为家里添置家具、改善设备，或攒钱解锁更多田地。
- **熟悉一个人或一种玩法**：跟进人物故事与约定，或在钓鱼、骑行等玩法中积累自己的记录。
- **继续向后成长**：提升职业等级、接触更高阶段内容，在原潮荣耀里推进章节、装备与赛事目标。

手机里的生活规划、职业履历、生活记录，以及成就和结局图鉴，可以帮助你回看已经做过的事、寻找接下来想达成的条件。游戏中的成就与结局有各自要求，是否追求它们，可以按自己的节奏决定。

## 下载与运行

1. 下载 **QianCity-v0.1.1-Windows-x64.zip**，完整解压到一个文件夹。
2. 双击 `QianCity.exe`。无需安装 Godot，也不需要联网。
3. 保持 `QianCity.exe` 和 `QianCity.pck` 在同一文件夹。

GitHub 自动生成的 Source code 压缩包只包含此仓库的说明和截图；可运行游戏请下载上方 Windows ZIP。

### 基本操作

| 按键 | 操作 |
| --- | --- |
| WASD / 方向键 | 移动 |
| E | 靠近目标后交互 |
| I | 背包 |
| M | 地图 |
| K | 属性 |
| P | 手机 |
| Esc | 返回、关闭普通弹窗或打开系统菜单 |
| 鼠标 | 按钮、选项与列表滚动 |

生活插曲需要完成一次选项选择。钓鱼与原潮荣耀的操作提示会显示在各自界面中。

### 存档与备份

游戏在稳定操作完成后自动保存。存档目录为：

`%APPDATA%\Godot\app_userdata\栖岸城：独居日记`

备份时复制整个文件夹，核心存档与城市存档一起保留。若玩过同名开发版，会读取同一存档目录。不要把本版本写入的存档交给更早版本读取。
