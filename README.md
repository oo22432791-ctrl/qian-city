# 栖岸城：独居日记

一款个人制作的城市生活模拟游戏。搬进栖岸城，从日常生活、工作与邻里关系中，慢慢建立自己的生活。免费提供个人作品试玩包。

## 下载与运行

[下载 v0.1.1 Windows x64 试玩版](https://github.com/oo22432791-ctrl/qian-city/releases/tag/v0.1.1)

1. 在发布页的 **Assets** 中下载 Windows x64 游戏 ZIP（约 145 MB）。
2. 完整解压，双击 `QianCity.exe`。无需安装 Godot，也不需要联网。
3. 保持 `QianCity.exe` 和 `QianCity.pck` 在同一文件夹。请勿直接在压缩包内运行。

GitHub 自动生成的 Source code 压缩包只包含此仓库的说明文件；可运行游戏请下载单独上传的 Windows ZIP。

## 可以体验什么

- 城市探索、居住与日常生活管理。
- 四条职业路线及各自独立的等级与经验成长。
- 农场经营：播种、浇水、施肥、收获和出售；初始开放一块地，其余两块花钱解锁。
- 雾河岸钓鱼、原潮荣耀等小游戏与邻里关系。

**自由体验 · 全地图开放** 适合先逛城市、体验内容；**开始正式成长** 按资金与职业进度逐步解锁。两个入口共用一个存档槽，开始新生活前请留意覆盖确认。

## 基本操作

| 按键 | 操作 |
| --- | --- |
| WASD / 方向键 | 移动 |
| E | 靠近目标后交互 |
| I | 背包 |
| M | 地图 |
| K | 属性 |
| P | 手机 |
| Esc | 返回、关闭普通弹窗或打开系统菜单 |
| 鼠标 | 按钮、选项与列表滚动 |

生活插曲需要完成一次选项选择。

## 存档

游戏在稳定操作完成后自动保存。存档目录为：

`%APPDATA%\Godot\app_userdata\栖岸城：独居日记`

备份时复制整个文件夹，核心存档与城市存档一起保留。若玩过同名开发版，会读取同一存档目录。不要把本版本写入的存档交给更早版本读取。

## 试玩状态与反馈

当前为预发布版。已检查启动、角色创建、农场经营、存档重启及备份恢复，尚未把所有后期路线从头打通。职业收益、成长速度与部分界面仍会调整；仅在当前 Windows 电脑验证运行。

全城交互与碰撞审计在游戏公司和设计事务所仍有未通过项，完整资产检查也有购车样本未通过。这些问题在旧包复查时同样存在，本版暂未修复。
